Five ways to draw the strip

Same six items in every frame (a long name, a three-digit price, an item with no saving and two with short stock), so each design is judged on the same data. ADD and the ticks work, and the count is shared, so add something in one and see it in the others.

My pick: A, with E as the fallback

A keeps what you asked for (a one-line name, the green price, the MRP struck beside or under it, one ADD) but moves the price next to ADD, so the eye reads the row left to right: what it is, then what it costs and how to add it. The words on the left are only two lines, so it does not feel stacked. E is the quietest if A still feels busy. D is the most different: worth it only if you want a "build the basket, add once" habit. C is for a very short strip. B repeats the other rails, so it adds the least.
